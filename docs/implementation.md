# 第一阶段实现状态

更新日期：2026-10-14。当前交付是阶段 1.1 的基础切片，不代表完整阶段 1 或 Nanite/Lumen 已完成。

## 已实现的运行路径

原生 WebGPU 初始化、能力检查、可诊断错误与设备丢失报告；TypeScript 运行时、WGSL 着色器、Vite 构建。运行场景只使用仓库生成的测试模型，不依赖下载或未授权的美术资产。

场景输入由通用 contracts 定义，不依赖 Three.js 或 Babylon.js。角色与树木通过不同的姿态生成函数驱动同一个四骨骼蒙皮程序。当前固定执行 Morph 然后蒙皮；这验证了共享机制，但还不是任意可组合的形变图编译器。

每批几何只执行一次 Compute，输出当前世界位置、法线和上一渲染帧位置。主视图和太阳阴影读取同一缓冲区。实例使用不复用的实体 ID，历史按 ID 管理，重置和视口尺寸变化使历史失效。变换与历史不依据对象类别分开处理。

表面使用不透明金属度/粗糙度 PBR、单方向光、1024 平方阴影图与比较采样。额外输出 rg16float 运动向量。环境补光是常量近似，不是世界空间 GI。地面网格仅用于测试场景的空间参照。

Rapier 以独立适配器提供盒子刚体和地面碰撞。模拟固定 60 Hz，显示读取插值姿态；卡顿追赶最多 5 步并记录丢弃时间。场景支持暂停、重置、添加和删除刚体。演示角色和树木尚无碰撞体。

运行诊断记录应用持有的 GPU buffer/texture 字节、实例和顶点数、CPU 编码提交时间，以及可用时的 GPU timestamp。该账本不包含驱动、WASM、浏览器和交换链内部占用；CPU 提交时间也不是整帧耗时。GPU 查询使用低频异步读回；几何读回仅在显式诊断时执行。

## 当前能力边界

| 能力 | 当前状态 |
| --- | --- |
| 统一形变执行 | 四骨骼线性蒙皮，一个位置 Morph，刚性骨骼矩阵 |
| 法线 | 蒙皮法线与实例逆转置；无通用 Morph 法线修正或切线重建 |
| 渲染调度 | 固定的形变、阴影、表面三个 pass；不是完整 Render Graph 编译器 |
| 材质 | 常量颜色、金属度、粗糙度；无纹理、Masked、透明、专用 BSDF 和材质 DSL |
| 资源 | 固定容量批次、初始化分配、尺寸变化时重建目标；无资产流送或自动预算管理 |
| 几何 | 常规索引绘制与实例化；无簇层级、LOD、遮挡剔除、虚拟几何 |
| 光照 | 直接光与阴影；无世界空间查询、GI 或反射 |
| 物理 | 地面与盒子刚体；无角色控制器、ragdoll、布料、破坏和查询 API |
| 平台 | WebGPU 必需；初始化失败明确报错，设备丢失报告后停止帧循环，恢复需要重新加载 |
| 性能 | 基础可测量切片；未完成大量动态物体、30 分钟稳定性及真实硬件性能验收 |

场景动画仍在 CPU 生成矩阵并逐帧上传所有活动实例。当前数据结构与分配方式用于建立正确性基线；大规模场景的增量更新、连续数据布局、Worker 和 GPU 姿态生成将在测量后推进。

Rapier compat 将 WASM 内嵌在 JavaScript，初始 bundle 较大。模块分包和 WASM 单独加载是后续加载性能任务，不能通过提高构建警告阈值当作解决。

## 验证入口

- npm run check：TypeScript、Vitest 数学/几何/物理/场景测试、生产构建。
- npm run test:browser：Chromium 软件适配器上的 WebGPU 编译、渲染、GPU 与 CPU 形变比较、重置、尺寸变化、实例操作与错误路径。
- 运行页的 GPU 验证按钮：显式读回角色与树木第一实例的全部顶点，对照 CPU 当前和前帧位置，误差门槛为 0.0002 世界单位。
- 运行页导出 JSON：记录本次环境与诊断；不等同完整 benchmark 报告。

软件适配器验证功能正确性，不证明目标 GPU 帧率或兼容所有浏览器。截图用于检查场景可见性；它不能替代后续的阴影、BRDF、运动向量和 GI 数值验收。

2026-10-14 本地结果：19 项 Vitest 测试通过；TypeScript 与生产构建通过。安装的 Chrome 154.0.8037.99 分别在 SwiftShader 和正常硬件配置下通过两项 Playwright 测试。硬件配置发现 NVIDIA Ampere 适配器，本机设备为 RTX 3070 Laptop GPU；这些是功能结果，不是固定场景性能基准。GPU 对照检查覆盖角色和树木共 432 个顶点的当前/前帧位置。

浏览器配置通过 PLAYWRIGHT_CHANNEL 选择已安装通道，通过 PLAYWRIGHT_GPU=hardware 禁用软件测试 flags。默认 Chromium for Testing 下载与系统浏览器是独立安装，测试不修改用户的日常浏览器配置。

## 阶段 1 的下一批工作

1. 把固定形变程序扩展为有边界、坐标系、依赖和历史声明的可编译算子组合；补齐 Morph 法线和动态边界。
2. 引入增量场景变更与资源版本，补充通用 pass 依赖检查，保留现有固定调度作为参考。
3. 添加资产导入、纹理、Masked 材质与覆盖一致性；从同一材质定义生成深度和阴影行为。
4. 增加数值光学与速度验收、真实 GPU 基线、浏览器/厂商矩阵及 30 分钟资源稳定性测试。
5. 完成阶段 1 剩余出口条件后，再进入虚拟几何与世界空间查询。详细目标见 roadmap.md。
